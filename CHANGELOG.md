# История версий DoubleColor OS

## x.0.02611.0 — 26.11.2026

Производительность и настройки в духе Windows 10.

- Chromium назначен браузером по умолчанию (`kdeglobals`);
- отключена индексация файлов Baloo — меньше нагрузки на диск и CPU;
- отключены блюр и фон-контраст KWin, ограничение композитора 60 FPS;
- добавлен `power-profiles-daemon` — профиль питания переключается в трее;
- кнопки окна справа (свернуть, развернуть, закрыть), как в Windows;
- файлы открываются двойным кликом (`SingleClick=false`);
- `vkd3d` для DX12-трансляции остаётся.

Kernel-античиты не поддерживаются — это ограничение архитектуры, а не сборки.

## x0.012612 — 26.11.2026

Интерфейс в стиле Windows 10, рабочие виджеты, поддержка пера и сетей.

- рабочая среда: KDE Plasma (Wayland) вместо i3; SDDM как экран входа;
  нижняя панель, меню приложений, системный трей, виджеты (`plasma-systemmonitor`,
  `kdeplasma-addons`), простые анимации KWin;
- вход: `sddm.service` в `graphical.target`; автологин root — только на Live,
  в установленную систему файл автологина не переносится;
- перо и планшеты: `libwacom`, модуль «Графический планшет» в составе Plasma;
- сеть: NetworkManager + `plasma-nm` (Wi-Fi и Ethernet), `bluedevil` (Bluetooth);
- браузер: `chromium` предустановлен; `install-chrome.sh` ставит Google Chrome из AUR
  (в официальных репозиториях Arch его нет);
- Windows-софт: добавлен `vkd3d` для трансляции DX12; Wine x86/x64 без изменений;
- компромисс: простой Plasma — 700–900 МБ ОЗУ вместо 350–500 МБ у i3.

Kernel-античиты не поддерживаются — это ограничение архитектуры, а не сборки.

## x0.012611 — 26.11.2026

Портативная сборка: систему можно поставить на USB-накопитель, работать на разных
компьютерах с сохранением данных и перенести на внутренний диск.

- установщик `doublecolor-portable`: GPT (BIOS boot + ESP + корень), `pacstrap`,
  минимальный `fstab` только для съёмного носителя, оба микрокода,
  загрузчик `--removable` (GRUB) или `--no-variables` (systemd-boot);
- шаблон `mkinitcpio.conf` для портативной системы: `block` и `keyboard` до `autodetect`,
  без привязки к конкретному железу;
- режим `--dry-run` — печатает все операции, ничего не меняя;
- защита от затирания носителя, с которого загружен Live-образ;
- раздел README «Перенос на внутренний диск»: dd/Clonezilla + chroot и tar-подход.

Установка на внутренний диск через `archinstall` сохранена без изменений.

## X0.01.2611 — 26.11.2026

Первая версия, зафиксированная под номером.

Имя файла сборки — `doublecoloros.iso`, без номера версии. Версия хранится в файле
`VERSION`, в `iso_application` внутри образа и в этом changelog.

Состав:

- ядро `linux-zen`, X11 + i3wm, автозапуск сессии на tty1;
- ZRAM размером в объём ОЗУ (zstd, приоритет 100), без swap на диске;
- `fstrim.timer`, лимит журнала 100 МБ, `swappiness=150`, `page-cluster=0`;
- окно «Диски» (`Super+N`): буква сверху, название снизу, схема A: для чистого
  диска и C: при наличии чужих ФС или другой ОС;
- монитор нагрузки `Ctrl+Shift+Tab` — `btop` в плавающем окне;
- Wine x86/x64 через new WoW64, установка префиксов скриптом;
- `multilib` включён и при сборке, и в установленной системе;
- установщик `doublecolor-install`: `archinstall` + перенос конфигурации
  DoubleColor в целевую систему + рабочий набор пакетов + `sudoers` для `wheel`;
- сборка ISO через `mkarchiso` локально или в GitHub Actions.

Известные ограничения:

- античиты уровня ядра (Valorant, CoD, Battlefield, Apex) не работают — это
  архитектурное ограничение Wine/Proton, а не настройка;
- EAC Linux v2 доверяет закрытому списку дистрибутивов, самосборка в него не входит;
- бинарный ISO этой версии ещё не собран: профиль готов, сборка запускается
  в CI или на Arch-машине.
